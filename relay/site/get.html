Let someone help you

TetherDesk QuickSupport is a small app for getting help. Open it and read the ID and one-time password to the person helping you. Nothing is installed, and a new password is made for every session.

Windows TetherDesk-QuickSupport.exe - Windows 10 / 11 Mac TetherDesk-QuickSupport-macOS.zip - macOS 12.3 or newer
  1. Windows: run the file. If a blue “Windows protected your PC” box appears, click More info, then Run anyway.
  2. Mac: open the zip, then open TetherDesk QuickSupport. If macOS says it can't check it, open System Settings › Privacy & Security and click Open Anyway. Allow Screen Recording and Accessibility when asked.
  3. Tell your helper the ID and password it shows.
  4. When you're done, click End session (or just close the window).

Helping someone? Connect in your browser - no download needed. Want to reach your own computers? See TetherDesk.
